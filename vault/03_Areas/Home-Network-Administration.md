# Home Network Administration

The ongoing responsibility of keeping the home network and self-hosted services running —
firmware updates, DNS entries, certificate renewals — independent of any single project. The
[[Home-Lab-Migration]] project is scoped to a finished migration; this area continues after it
closes.

## What lives here

- Recurring maintenance not tied to the migration: router firmware, certificate renewal dates,
  DNS zone notes.
- Longer-lived network decisions that outlive any one project, including ones the migration
  project currently defers — see [[Network-Topology]] for what's in scope for the migration
  specifically vs. what stays here.
- Incident notes for anything that breaks outside of a project's runbook.

## Relationship to the migration project

The migration project will close once the new tower is fully in service; this area doesn't close
— it's what the tower gets handed off *to*. See [[PARA-Method]] for the general
project-vs-area distinction this is an instance of.
