# Vault CLAUDE.md — v0 Draft

An early draft of what became `contract/templates/VAULT_CLAUDE.md`. This version tried to include
the full distill workflow inline — every step, every failure mode — directly in the always-loaded
file, before the progressive-disclosure split moved that depth into a skill's reference material
instead.

Kept frozen as a record of the earlier approach, not as an alternative anyone should follow now.
The current template supersedes it entirely; this draft is not linked to from active content.
