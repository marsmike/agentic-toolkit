# Deprecated Plugin — notebooklm

A v1-era plugin integrating with an external notebook-summarization tool. Archived during
curation rather than carried into the current plugin set: its behavior overlapped almost entirely
with capability the core retrieval and distillation plugins already cover, and nobody could state
a specific behavior it delivered that those didn't — the exact failure of the scope test a
curated plugin is expected to clear.

Frozen here, not deleted, in case it earns re-entry later on different merits. This note is not
linked to from any active content in this vault, on purpose — that's the expected state for an
archived note, not an oversight to fix.

*Archived 2026-01-05, curation wave 1.*
