# Home Lab Migration

Migrating a handful of self-hosted services (media library, a small git remote, a backup target)
off a five-year-old mini-PC onto a refurbished tower before the old hardware's fans finally give
out. Closable outcome: everything running on the new box, old box repurposed or retired. Draws on
the ongoing [[Home-Network-Administration]] area but is scoped to end, unlike that area.

## Scope

- New hardware racked and networked — see [[Network-Topology]].
- Services migrated one at a time per [[Migration-Runbook]], never all at once.
- Backups verified on the new target before the old box is touched — see [[Backup-Strategy]].
- Current hardware and service inventory in [[Hardware-Inventory]].

## Status

Two of five services migrated. Weekly cadence in [[Weekly-Review]] (this project's — see
[[Field-Guide-Project]] for the other project using the same weekly-review note name, on purpose;
[[Test-Corpus-Map]] documents why).
