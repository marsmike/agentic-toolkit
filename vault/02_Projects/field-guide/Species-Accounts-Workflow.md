# Species Accounts Workflow

Every account in the [[Field-Guide-Project|field guide]] follows the same five steps, so quality
doesn't depend on remembering which shortcuts were taken last time:

1. **Range and status** — pull current range data from [[Reference-Library]], note any recent
   range-shift reports.
2. **Field marks** — identification notes, written for the intermediate birder this book targets,
   not the expert.
3. **Voice** — song/call description; the hardest section to write well in prose, deliberately
   short.
4. **Similar species** — cross-link to the accounts most likely to be confused with this one.
5. **Art** — hand off to [[Illustration-Sourcing]] once the text is stable, not before; illustrating
   a description that's still changing wastes the artist's time.

## Batching discipline

Reviewing accounts by taxonomic family instead of by the order they were drafted cut review time
this week — see the [[Weekly-Review|weekly review]]. Worth keeping as the default going forward.
