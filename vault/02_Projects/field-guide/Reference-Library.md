# Reference Library

Source material shared across every [[Species-Accounts-Workflow|species account]] rather than
duplicated per-account: two prior regional field guides used for cross-checking range claims, a
subscription to a regional records database for recent range-shift reports, and notes from two
museum collection visits for plumage variation that photos alone don't show well.

Kept as one project note rather than a folder per source — at this project's size (a few dozen
citations), a folder would be overhead for no retrieval benefit; see
[[Vault-Größe-und-Skalierungsschwellen]] for the general version of that threshold judgment.
