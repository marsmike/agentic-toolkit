# Judgment fixtures

Synthetic captures for `eval_distill_judge`'s live phase and the `judgment-calibration`
skill. Each one is written so that one judgment has an answer known by construction (a
repost of a note's source, a claim that contradicts a note, an empty stub, a near-copy of
a sibling). They live here, not in `vault/01_Capture/`, so the published example vault
keeps its three hand-written captures; the golden file refers to them by this path and
they are read in place, never copied into a vault.
